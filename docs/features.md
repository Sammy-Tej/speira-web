# Speira: every feature, built and planned

As of 15/10/26. **Built** means it works in the web app today. **Planned** means we've agreed it but not built it yet.
The native apps (iPad, Mac, TV) only have the very first screen so far, so this list is what they *could* contain.

| Feature | Status |
|---|---|
| Two round rings (96/150, 105/144), roll inside or outside | Built |
| Two straight bars (84, 108) with rounded ends, any angle | Built |
| Oval, triangle and square rings with two toothed edges, any angle | Built |
| Fixed wheel: pin a wheel (24–84) and roll another round it | Built |
| 18 wheels, 24 to 84 teeth | Built |
| Pen holes, pick from a slider or by clicking the wheel | Built |
| Start shift and auto shift | Built |
